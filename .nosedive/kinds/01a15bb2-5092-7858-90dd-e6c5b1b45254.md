# Dive

A dive is one attempt on a feat. It is not durable: once it is over, it can go.

`jump` mints it on its feat, named `<feat name>.<last 6 of its id>`, in the directory of the root that reaches its feat. The feat links it as `dives.feat`, so the tree shows a feat's dives in a section of their own: a dive is a non-durable feat. The dive names its feat in `meta.feat`, as legacy dives do, and links nothing back. Its `scopes` copy the feat's.

- `meta.diver` is who holds it, by git's `user.email`, and null when nobody does.
- `meta.packer` is who last put it down.
- `meta.outcome` is `landed` or `bailed` once it is over, and absent while it is open.

Each action that changes a dive appends a section to it, `## <Action> <iso time>`, saying what it did, scope by scope.

## On deck

A hero repo has at most one dive on deck: the one this checkout of the hero is working, named by id in `.nosedive/local/dive`, which git ignores. jump puts it there; pack, bail and land take it off.

## Work stays in git

A dive's work is never copied into the hero. In each writable scope it is the commits of the dive's local branch, `<hero id>/<hero branch>/<dive id>` in the user's cache (core's hydrate-repo names it), that the scope's work branch on origin lacks. pack pushes them to `refs/nosedive/dives/<hero id>/<hero branch>/<dive id>` on origin: a ref outside `refs/heads`, so no branch listing shows it and no clone fetches it, yet any hero finds a dive's ref by its id, the name's last part.

Commits a checkout holds that no ref on origin does are never dropped: when jump or bail moves the checkout off them, they are pushed first to `refs/nosedive/orphans/<hero id>/<hero branch>/<sha>`, where an audit across repos can find them.

## Ignored files

A scope's ignored files stay out of git. pack, land and bail zip its keepable ones, every ignored file but those under a `node_modules`, `dist` or `build` directory, to the feat's pack, `.nosedive/local/packs/<feat id>/<repo name>.zip`, replacing it, or deleting it when there are none; a bailed dive's `.env` waits there for the feat's next dive. jump unzips the feat's pack over the checkout and keeps it. A checkout jump moves from other work first has its keepable ignored files zipped to `.nosedive/local/packs/orphans/<repo name>-<time>.zip`, unless they match the repo's newest pack, then removed, so a feat never sees another's.
