# Jump

`<ref>` is a feat's or a dive's quid. A feat is any doc one of the hero's roots reaches through links whose rel ends `.feat`, a root of kind cape aside, since its feats are actions, a memo unless it has a kind of its own; a doc nothing reaches that way is refused, naming how to link it in. Its `scopes` name the repos it works in, legacy's shape: an entry keyed by a repo doc's quid, with `work-branch` naming the branch its work goes to, and an entry with none, or a bare quid, read-only.

- **A feat**: mints a dive on it (see [dive](01a15bb2-5092-7858-90dd-e6c5b1b45254.md)), copying its scopes, naming the feat in its `meta.feat`, and linking it from the feat as `dives.feat`, in one commit; then jumps it.
- **A dive**: refused when it is over, when someone else holds it, or when another dive is on deck. Jumping the dive already on deck jumps it again: a checkout already where the dive wants it is the diver's, left as it is, and only the rest move.

A checkout with uncommitted changes or untracked files is refused before anything moves, naming each. Then, for each scope:

- **Writable**: the checkout is put on the dive's local branch, hydrated for the dive with core's hydrate-repo when it is missing, moved when it is there for other work. Where the dive's ref on origin, pushed from any hero, holds what the branch lacks, the branch moves to it. When the work branch on origin has moved on, the dive's work is rebased onto it; a rebase that conflicts is left in progress, named, for the pilot to finish with `git rebase --continue`, and jump exits 1 before recording anything.
- **Read-only**: the checkout is detached at origin's trunk, hydrated or moved the same way.

Commits a moved checkout held that no ref on origin does are pushed to an orphan ref first (see dive). Then each checkout moved from other work has its ignored files swapped for the feat's pack (see dive), and pack's `work in progress` commit is undone, so the work it held comes back uncommitted.

It sets `diver`, clears `packer`, appends `## Jumped`, puts the dive on deck, and prints the dive's path, its feat's and each checkout's.
