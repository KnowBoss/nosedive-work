# Turn

## Usage

`pass --turn <dive> [<summary>] [--next <gist>] [--label <label>]` records progress on the dive this worktree holds, as found by dive-on-deck. A different dive is refused. `-` as summary reads stdin.

Append a section headed `## <ISO 8601 timestamp>[ <label>]`, then the summary when given, then `Next: <gist>` when given. Use core's hero-zone timestamp helper once available; until then use UTC with `Z`. Refuse when neither summary nor next is given, or next contains more than one line. Two turns append in order. Edit through pass so each turn makes one ordinary pass commit. The gate sets no commit subject; core's pass owns it.
