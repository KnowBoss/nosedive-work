# Turn

## Usage

`pass --turn <dive> [<summary>] [--next <gist>] [--label <label>]` records progress on the dive on deck, the one the hero's dive branch names, as found by dive-on-deck. A different dive is refused. `-` as summary reads stdin.

Append a section headed `## <ISO 8601 timestamp>[ <label>]`, then the summary when given, then `Next: <gist>` when given. Use core's hero-zone timestamp helper once available; until then use UTC with `Z`. Refuse when neither summary nor next is given, or next contains more than one line. Two turns append in order. Edit through pass so each turn makes one ordinary pass commit. The gate sets no commit subject; core's pass owns it.

## Where a turn lives

A turn is committed on the dive branch only and pushed nowhere (turns-publish-when). It stays a pass gate (turn-stays-a-pass-gate), so each turn is one ordinary pass commit on the dive branch; the dive's home, the branch it was jumped from, and its upstream are not touched, so main shows no noise while the dive is worked. Once pass has committed it prints, and exits 0:

`turn: <sha> committed on the dive branch only, not pushed; land, pack or bail publishes it`

The next land, pack or bail publishes it: each builds its record on the dive branch's copy of the dive doc, which holds every turn section, so the one record commit it pushes carries them all, and the record's lines say `- turns: <n>`. Land and jump leave the turn commits themselves out of the hero work they replay, so a section is never doubled (see land and jump). A record refuses, changing nothing, when the home's copy of the dive doc changed since the dive began: every turn stays on the dive branch (see dive-on-deck).

Until then a turn exists only on the local dive branch, so an unpacked worktree's turns are lost with it, as the dive's other unpacked work is. Pack and bail also keep them in the dive's refs. A core that gives gates no `ctx.committed` prints the line without a sha.

The dive doc is changed only by turns and records while the dive is held: crud refuses to edit it (held-dive-doc-edits, see dive-shape). A dive in flight whose turns already reached main under turns-on-jumped-branch still lands: its record is built on the dive branch's copy when that begins with the home's.
