# Dive on deck

Finds the dive this worktree holds, walking the feats the hero's roots reach for open dives whose `diver` carries its holder token (see [dive](01a15bb2-5092-7858-90dd-e6c5b1b45254.md)), and returns it with the feat its `meta.feat` names and its scopes. Given a dive's quid, it returns that one, refusing it unless this worktree holds it. With none it refuses, naming `jump`; with several, it refuses naming each, with the repos on its branch and the commits each holds origin lacks, so the pilot can name one.

Each scope carries its repo doc, its checkout, the repo's trunk, the work branch, if any, and whether its checkout is the dive's: on the dive's local branch when writable, present when read-only. Nothing is hydrated or moved.
