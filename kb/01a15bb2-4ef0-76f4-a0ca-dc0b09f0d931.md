# Feat

A feat is work worth doing, kept and maintained: it stays after its dives are over. It lives in the ship's kb, and its tree of dives hangs under it.

Its `scopes` name the repos it works in, the shape legacy wrote, so a legacy feat reads as it is. Each entry is keyed by a repo doc's quid, the repo being registered in the ship, and `work-branch` names the branch its work goes to:

```yaml
scopes:
  - 01a15bb2-…:            # the repo doc
      work-branch: work/ideas
```

A scope with no `work-branch` is read-only: checked out for context, never pushed. A legacy entry that is a bare quid is read-only too.
