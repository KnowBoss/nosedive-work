# Merge

Gets a feat's work into trunk, the step legacy left to pull requests. `<feat>` is the feat's quid.

Refused while any dive the feat links as `dives.feat` is open. For each writable scope whose work branch exists on its remote, it merges the branch into trunk in a scratch checkout of the repo's cache: a fast-forward when trunk has not moved, else a merge commit. Any conflict refuses the whole merge, naming the repo, before anything is pushed. Then it pushes each trunk, deletes each work branch, and appends `## Merged` to the feat.
