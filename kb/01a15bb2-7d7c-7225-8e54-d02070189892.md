# Writes a dive's changes: meta set, a dated section appended, committed to the ship, pushed when the ship's branch has an upstream

Every change an action makes to a dive goes through it: the meta it sets (null clears a field), an `## <Action> <iso time>` section appended with the lines it is given, and any other ship docs it is handed, all committed to the ship in one commit, `<action>(<dive name>): <summary>`. The ship is pushed when its checked-out branch has an upstream; when that push fails, the commit stays and the failure is said, not thrown.
