# Record dive

Every change an action makes to a dive goes through it: the meta it sets (null clears a field), a `## <timestamp> <label>` section appended (labels `jumped`, `packed`, `landed`, `bailed`; timestamp ISO 8601 UTC with `Z`, as pass --turn heads its own) with the lines it is given, and any other hero docs it is handed, all committed to the hero in one commit, `feat(<feat name>): <action> <summary>`, or `<action>: <summary>` when the hero does not hold the dive's feat, which ends with the nosedive co-author trailer (see commit-message) like every commit the loop makes in the hero. It is given the core version for that trailer. Dives written with the old `## Jumped <timestamp>` headings stay as they are; nothing in the loop reads sections by heading. Pushing is the action's: each puts its commit on the hero's trunk on origin.
