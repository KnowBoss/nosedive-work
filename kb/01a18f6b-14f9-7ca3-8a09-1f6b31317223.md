# Record turn

Finds the passing dive through dive-on-deck, refusing unless this worktree holds it. Validates a nonempty summary or next, and a next gist without line breaks. Appends the UTC ISO timestamp (until core's hero-zone helper lands), optional label, summary and Next gist through the current pass edit. It writes no files or commits directly. The gate entrypoint reads a stdin summary before calling it. Integration tests exercise it through the real launcher and pass, including one commit per turn.
