# Land

## Usage

`<dive>` names it when this worktree holds several. Refused, before anything is pushed:

- while the hero or a checkout has uncommitted changes, naming each: commit them first;
- while a read-only scope has commits origin lacks;
- while a work branch has moved to a commit the scope's HEAD does not contain. The recourse is `pack`, then `jump`, which rebases the work onto the branch.

Each commit it publishes that no branch on origin holds is stamped first with `Nosedive-Dive: <dive id>`, `Nosedive-Feat: <id>`, the dive's first durable feat ancestor (see [dive](01a15bb2-5092-7858-90dd-e6c5b1b45254.md)), and the nosedive co-author trailer (see commit-message), where the commit lacks them. A commit that carries a nosedive co-author already, of any version, from an earlier stamp or a rebase, gets no second; another's co-author does not stand in for it. The hero's record, `land(<dive name>): <summary>`, carries it too.

Each writable scope whose checkout is on the dive's local branch and holds work its work branch lacks is pushed to it, a fast-forward or the branch's creation; any other is unchanged. Then each scope's ignored files are packed for its feat, every ref of the dive is deleted on origin, and each checkout is left detached at what it holds, its local branch deleted.

The hero's own work rides to its trunk: `outcome: landed` set, `diver` cleared and a `## <timestamp> landed` section recording each push are committed on top of it, and the hero's branch is pushed to trunk, rebased onto it first when trunk moved meanwhile.
