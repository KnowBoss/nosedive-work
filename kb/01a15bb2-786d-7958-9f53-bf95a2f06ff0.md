# Land

Publishes the dive on deck. Refused, before anything is pushed:

- while a checkout has uncommitted changes, naming each: commit them first;
- while a read-only scope has commits origin lacks;
- while a work branch has moved to a commit the scope's HEAD does not contain. The recourse is `pack`, then `jump`, which rebases the work onto the branch.

Each writable scope with work its work branch lacks is pushed to it, a fast-forward or the branch's creation; one with none is unchanged. Then each scope's ignored files are packed for its feat (see [dive](01a15bb2-5092-7858-90dd-e6c5b1b45254.md)), every ref of the dive is deleted on origin, and each checkout is left detached at what it holds, its local branch deleted. `outcome: landed` is set and `diver` cleared, `## Landed` records each push, and the dive goes off deck.
