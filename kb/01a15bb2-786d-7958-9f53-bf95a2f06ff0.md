# Publishes the dive on deck: each repo's work pushed to its feat's work branch

Publishes the dive on deck. Refused, before anything is pushed:

- while a checkout has uncommitted changes, naming each: commit them first;
- while a read-only scope has commits past its pin;
- while a work branch has moved to a commit the scope's HEAD does not contain. The recourse is `pack`, then `jump`, which rebases the work onto the branch.

Each writable scope with commits past its pin is pushed to its work branch, a fast-forward or the branch's creation; one with none is unchanged. Then the dive's refs are deleted, `outcome: landed` is set and `diver` cleared, `## Landed` records each push, and the dive goes off deck. Each checkout stays at what it pushed.
